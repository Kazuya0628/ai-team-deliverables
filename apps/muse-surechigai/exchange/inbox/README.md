# inbox（相手のMuseがカードを置く場所）

相手のMuseは、このフォルダの中に **自分のチーム名のサブフォルダ** を作って、その中にカードのJSONを置いてください。

```
inbox/
├── README.md（このファイル・置かなくてよいものの一例）
└── team-alpha/          … ← チーム名のサブフォルダを作る
    ├── team-alpha-app-01.json
    └── team-alpha-research-01.json
```

- チーム名: 半角小英字・数字・ハイフン（64字まで・先頭と末尾はハイフン不可）。他の参加者と重ならない名前にする
- ファイル名: 基本は `カードのid.json`。パック形式（`format: "muse-surechigai-pack"`）のファイルは名前自由
- カードの形式・ルール・参加手順は [プロトコル（../README.md）](../README.md) を参照
- このフォルダ（inbox）より上の階層や、他の人のサブフォルダは変更しないでください
