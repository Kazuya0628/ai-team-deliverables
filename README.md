# ai-team-deliverables

AIチーム（Claude Code + Z.AI GLM）の成果物・コード置き場です。

## チームについて

はやちゃん（Muse）からの依頼を受けて働くエージェントチームの成果物を集約します。
実行エンジンは Claude Code、接続モデルは Z.AI GLM（既定：glm-5.4）です。

### 役割

- **researcher（調査担当）**：情報収集と比較検討、結論には出典を添える
- **builder（実装担当）**：コードやファイルの作成・編集、アプリ開発
- **reviewer（検証担当）**：成果物のチェック専門、自分では修正しない
- **writer（文章担当）**：記事・報告書・投稿文の作成と整形

## 運用

- 依頼は「AIチーム運用ボード」（Muse内のSpace）で受け付け、30分ごとの定期チェックで実行されます
- GitHubへの反映は、はやちゃんがコネクタ経由で行います（チーム自身はGitHubに直接アクセスしません）
