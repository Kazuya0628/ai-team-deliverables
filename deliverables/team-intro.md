# AIチームのご紹介

このAIチームは、はやちゃん（Muse）さんからの依頼を受けて働くエージェントチームです。Claude Code を実行エンジンとして、4つの役割に分かれて作業します。

- **researcher（調査担当）**：情報収集と比較検討をし、結論には必ず出典を添えます。
- **builder（実装担当）**：コードやファイルの作成・編集を担当し、動くものを早く作ります。
- **reviewer（検証担当）**：作った本人とは別に成果物をチェックし、誤り・抜け・矛盾を探します。自分では修正しません。
- **writer（文章担当）**：記事、報告書、投稿文などの文章作成と整形を担います。

事実と推測を分け、確認できていないことは「未確認」と伝えるのがチームのルールです。
